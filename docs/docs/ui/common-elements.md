# Общие shared-компоненты

В разделе показаны только самостоятельные компоненты верхнего уровня. Внутренние части составных
компонентов отдельно не описываются.

## Background

![Пример Background](/img/shared/background.png)

Создаёт общую фоновую область страницы с мягкими цветовыми переходами и декоративными линиями.
Содержимое отображается поверх фона.

## Switch

![Пример Switch](/img/shared/switch.png)

Переключает состояние между двумя вариантами. В приложении используется для смены светлой и тёмной
темы.

## Popper

![Пример Popper](/img/shared/popper.png)

Показывает небольшую всплывающую панель рядом с выбранным элементом. Панель подходит для коротких
форм и дополнительных действий, не уводящих пользователя с текущего экрана.

## Stepper

![Пример Stepper](/img/shared/stepper.png)

Показывает последовательность шагов и помогает различать завершённый, текущий и следующий этапы.
В приложении используется для планирования цели и отображения прогресса.
