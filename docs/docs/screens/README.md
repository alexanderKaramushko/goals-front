# Экраны приложения

Индекс содержит маршруты, зарегистрированные в `src/app/App.tsx` и `src/app/routes.ts`, а также
значимые состояния этих экранов. Параметры пути и query-параметры не используются.

| Страница                                                 | Маршрут            | Доступ                | Статус документации |
| -------------------------------------------------------- | ------------------ | --------------------- | ------------------- |
| [Вход](./login.md)                                       | `/login`           | Публичный             | Готово              |
| [Цели](./goals.md)                                       | `/app`             | Требуется авторизация | Готово              |
| [Новая цель: просмотр и действия](./new-goal-actions.md) | `/app`             | Требуется авторизация | Готово              |

## Авторизация маршрутов

Отдельного route guard в приложении нет. Компонент верхней панели запрашивает профиль через
`GET /auth/users/profile` и при ответе `401` перенаправляет пользователя на `/login`. Другие
ошибки профиля не вызывают редирект. API целей дополнительно проверяет cookie `jwt` на backend.

## Не реализовано

Кнопка «Посмотреть цели» присутствует в карточке пользователя, но обработчик и маршрут страницы
целей выбранного пользователя отсутствуют. Такой экран не включён в каталог реализованных страниц.
