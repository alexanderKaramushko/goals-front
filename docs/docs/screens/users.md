# Пользователи

## Назначение

Экран показывает пользователей системы и краткую статистику их активных и завершённых целей.

## Маршрут

`/users`

Параметры пути и query-параметры не используются.

## Доступ

Только для аутентифицированного пользователя. При `401` запроса профиля верхняя панель выполняет
переход на `/login`; отдельного route guard нет.

## Состояния страницы

### Данные загружены

Для каждого пользователя отображается карточка. Количество активных и завершённых целей вычисляется
на frontend из отдельного списка целей пользователя.

### Пустое состояние

Специального сообщения нет: при пустом массиве пользователей список остаётся пустым.

### Загрузка

Отдельный loader или skeleton не реализован. До ответа API список выглядит пустым. Цели каждой
карточки загружаются независимо, поэтому сначала отображаются нулевые значения.

### Ошибка

Ошибки чтения пользователей и целей не показываются. Хуки возвращают пустые массивы, визуально
неотличимые от реального отсутствия данных.

## Действия пользователя

| Действие                  | Условие               | Результат                                           |
| ------------------------- | --------------------- | --------------------------------------------------- |
| Перейти на вкладку «Цели» | Профиль загружен      | Переход на `/app`                                   |
| Нажать «Посмотреть цели»  | Карточка отображается | Результата нет: обработчик и маршрут не реализованы |
| Переключить тему          | Всегда                | Меняется цветовая схема                             |

## Используемые API

| Назначение                 | Метод и endpoint                      | Когда вызывается                          |
| -------------------------- | ------------------------------------- | ----------------------------------------- |
| Профиль для верхней панели | `GET /auth/users/profile`             | При открытии страницы                     |
| Список пользователей       | `GET /api/v1/users/get-all`           | При открытии страницы                     |
| Цели пользователя          | `GET /api/v1/targets/get-all/:userId` | Отдельно для каждой карточки пользователя |

К запросам goals-service добавляется `x-user-timezone`.

## Используемые общие компоненты

- [`Background`](../ui/common-elements.md#background) — фон страницы;
- [`Switch`](../ui/common-elements.md#switch) — смена темы.

## Особенности и ограничения

- количество запросов целей растёт линейно с числом пользователей (`N+1`);
- статистика учитывает только статусы `active` и `completed`;
- кнопка просмотра целей пока декоративна;
- экран просмотра целей выбранного пользователя и маршрут с `userId` отсутствуют;
- loader, сообщение об ошибке и явное пустое состояние не реализованы.
