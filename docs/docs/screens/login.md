# Вход

## Назначение

Публичная точка входа в приложение. Страница знакомит пользователя с приложением и переводит его
в Google OAuth через отдельный auth-сервис.

## Маршрут

`/login`

Параметры пути и query-параметры не используются.

## Доступ

Публичный. Автоматического перенаправления уже авторизованного пользователя с `/login` нет.

## Состояния страницы

### Данные отображены

Заголовок и кнопка появляются с fade/motion-анимацией. Фон включает декоративные линии.

### Ошибка профиля

Профиль запрашивается общей верхней панелью даже на публичном маршруте. Отдельное сообщение об
ошибке не отображается; при `401` пользователь остаётся на `/login`.

Отдельных состояний загрузки и пустого состояния у формы входа нет.

## Действия пользователя

| Действие         | Условие                                         | Результат                                                   |
| ---------------- | ----------------------------------------------- | ----------------------------------------------------------- |
| Нажать «Войти»   | Настроены `VITE_GOALS_AUTH_API` и `VITE_APP_ID` | Переход на `auth/google-oauth/login?appId=...` auth-сервиса |
| Переключить тему | Всегда                                          | Меняется цветовая схема приложения                          |

## Используемые API

| Назначение                           | Метод и endpoint                                                                   | Когда вызывается                |
| ------------------------------------ | ---------------------------------------------------------------------------------- | ------------------------------- |
| Получение профиля для верхней панели | `GET /auth/users/profile`                                                          | При монтировании верхней панели |
| Запуск OAuth                         | переход на `GET {VITE_GOALS_AUTH_API}/auth/google-oauth/login?appId={VITE_APP_ID}` | По нажатию «Войти»              |

## Используемые общие компоненты

- [`Background`](../ui/common-elements.md#background) — фон и декоративные линии;
- [`Switch`](../ui/common-elements.md#switch) — переключатель темы внутри верхней панели.

## Особенности и ограничения

- путь OAuth строится из переменных окружения, а не из axios-клиента;
- верхняя панель не скрывается на странице входа;
- ошибки запуска OAuth не обрабатываются внутри интерфейса;
- cookie создаёт auth-сервис; frontend напрямую её не записывает.
