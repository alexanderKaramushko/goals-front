# Создание цели

## Назначение

Форма создаёт цель и её последовательные шаги. Данные шагов редактируются до отправки и сохраняются
после успешного создания цели.

## Маршрут

`/app/create-goal`

Параметры пути и query-параметры не используются.

## Доступ

Только для аутентифицированного пользователя. Механизм доступа совпадает со [страницей целей](./goals.md#доступ).

## Состояния страницы

### Начальное состояние

Поля цели пусты, создан один шаг «Новый шаг». Кнопка «Сохранить» отключена.

### Редактирование шага

По клику на шаг открывается `Popper` с названием, датой и описанием. Между шагами доступна кнопка
вставки промежуточного шага; отдельной кнопки подтверждения редактора нет, значения применяются сразу.

### Сохранение

На кнопке отображается loading-состояние, пока создаётся цель или очередной шаг. После успешного
создания всех записей выполняется переход на `/app`.

### Ошибка

Ошибка любого запроса показывается через snackbar. Введённые значения остаются на странице.
Отдельного inline-состояния ошибки нет.

## Действия пользователя

| Действие                   | Условие                                                           | Результат                                                          |
| -------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------ |
| Заполнить данные цели      | Всегда                                                            | Обновляется локальная модель цели                                  |
| Открыть шаг                | Шаг существует                                                    | Появляется редактор шага                                           |
| Добавить промежуточный шаг | Между двумя шагами                                                | Новый шаг вставляется по выбранному индексу                        |
| Добавить шаг               | Всегда                                                            | Новый шаг добавляется в конец                                      |
| Удалить шаг                | Шаг существует                                                    | Шаг удаляется только из локальной формы                            |
| Сохранить                  | Название и описание цели, а также все поля каждого шага заполнены | Создаётся цель, затем её шаги; при полном успехе переход на `/app` |

## Используемые API

| Назначение                 | Метод и endpoint                      | Когда вызывается                                     |
| -------------------------- | ------------------------------------- | ---------------------------------------------------- |
| Профиль для верхней панели | `GET /auth/users/profile`             | При открытии страницы                                |
| Создание цели              | `POST /api/v1/targets/create`         | Первым после нажатия «Сохранить»                     |
| Создание шага              | `POST /api/v1/steps/create/:targetId` | Последовательно для каждого шага после создания цели |

Axios-клиент goals-service добавляет `x-user-timezone`. Даты отправляются в формате `YYYY-MM-DD`.

## Используемые общие компоненты

- [`Background`](../ui/common-elements.md#background) — фон страницы;
- [`Switch`](../ui/common-elements.md#switch) — смена темы;
- [`Stepper`](../ui/common-elements.md#stepper) — редактор последовательности;
- [`Popper`](../ui/common-elements.md#popper) — редактор выбранного шага.

## Особенности и ограничения

- frontend разрешает сохранить форму без даты завершения цели: `isFormFilled` не проверяет
  `targetData.shouldBeCompletedAt`; backend отклонит такой запрос с `400`;
- после удаления всех шагов `every()` возвращает `true`, поэтому frontend допускает цель без шагов;
- цель и шаги создаются отдельными последовательными запросами без общей транзакции: ошибка шага
  может оставить уже созданную цель и часть шагов;
- повторное нажатие после частичного успеха может создать дубликат цели;
- срок шага ограничен соседними шагами и сроком цели только на уровне DatePicker;
- ошибка backend отображается только snackbar и не привязывается к конкретному полю.
